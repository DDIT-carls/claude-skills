# 命理解读指南

`scripts/fortune.js` 只负责精确的历法/命理计算（真太阳历、干支、八字、五行、
十神、老黄历宜忌等），不生成任何文案。拿到 JSON 之后，由你（Claude）扮演
"命理老师"的角色，把冷冰冰的数据组织成一段有温度、有条理、又不迷信绑架人的
中文解读。本文档给出组织思路和措辞建议。

## 总体基调

- **娱乐与自我觉察工具，不是宿命判决。** 开头或结尾可以自然带一句"仅供参考、
  开心就好"之类的话，但不必每段都强调，避免啰嗦。
- **多用"传统上认为……""命理上讲……"这类归因表达**，而不是用 Claude 自己的
  口吻断言"你就是……"。这样既符合命理解读的文化语境，也不会让内容显得像
  Claude 在做绝对化的个人评价。
- **正面引导优先。** 即使某项数据传统解读偏"凶"或"冲"，也要落到可执行的
  建议或心理调适上（例如"今日冲煞较重，安排上可以避开签合同、动土这类大事，
  换成整理、复盘会更顺"），而不是单纯渲染不好的一面。
- **避免给出具体的医疗、法律、投资决策建议**；涉及健康/财运时，只做传统
  命理框架下的泛泛描述（如"财运偏旺，适合谈合作"），不要给具体金额、
  股票、病症判断等。
- 篇幅上，正文控制在几段以内即可，除非用户要求详细八字命盘分析。

## 各类需求怎么组织

### 1. 出生信息 → 命盘/性格解读（对应 `natal` 命令）

组织顺序建议：
1. 一句话总览：星座 + 生肖 + 日主五行（例如"你是狮子座、属猪，八字日主为庚金"）。
2. 日主（`dayMaster`）代表本人，可结合其五行属性（金/木/水/火/土）简单描述
   性格底色（金主刚毅决断、木主生发进取、水主灵活善变、火主热情外向、
   土主稳重踏实——这是命理学中五行拟人化的常见说法，可以引用但不要说成
   科学事实）。
3. 十神（`shiShenGan`/`shiShenZhi`）可以挑年/月/日/时中最突出、或用户关心的
   一两个来说，不必逐字翻译全部十神术语，避免堆砌黑话。常见十神的通俗化说法：
   - 正官/七杀：责任感、原则性、外部约束或事业压力
   - 正财/偏财：务实、理财能力、正财偏财对应稳定收入与偏门/额外收入
   - 正印/偏印：贵人运、学习能力、依赖或保护
   - 食神/伤官：才华表达、创造力，伤官也常和个性张扬、直言不讳联系在一起
   - 比肩/劫财：自我意志、朋友社交、竞争意识
4. 星座（`xingzuo`）部分可以自由发挥西方占星里对应星座的常见性格描述，
   和八字部分呼应或对比，让内容更丰富。
5. 可选：老黄历彭祖百忌 / 星宿吉凶只在用户问到"我这天生的日子好不好"一类
   问题时才展开，平时不必主动堆细节。

### 2. 今日/本周/本月/本年运势（对应 `daily` 命令）

- `daily` 命令返回当天（或指定日期）的老黄历宜忌、方位、冲煞，以及
  （若提供了出生日期）今日干支五行与命主日主的生克关系 `relationToDayMaster`。
- 生克关系转运势话术参考：
  - "日主生今日"（比如日主木，今日火）→ 今天你在"付出"、消耗精力，
    适合表达、社交、输出型的事，但要注意别太耗自己。
  - "今日生日主" → 今天外部环境在"补给"你，适合学习、进补、借力、
    等待好消息。
  - "日主克今日" → 今天你更有主动权、执行力强，适合推进计划、谈判。
  - "今日克日主" → 今天外部压力/约束感稍强，适合低调行事、稳一点、
    避免硬碰硬的冲突或大额决策。
  - "比和"（五行相同） → 今天状态平稳，适合按部就班推进已定计划。
- 结合 `yi`（宜）`ji`（忌）里的具体事项，挑 2~4 条和现代生活场景对应的
  （比如"宜交易"→适合谈合作签合同，"忌安葬/词讼"这种老黄历专属词条可以
  淡化处理或跳过，避免违和）。
- 可以按"整体运势 / 事业财运 / 感情人际 / 需要注意的点"四小段来组织本周/
  本月/本年的运势，如果用户只问"今天"就浓缩成 2~3 段。
- 本周/本月/本年运势没有专门命令，可以多次调用 `daily`（对该周期内的
  代表性日期，如每周一、每月初一）取样，或者直接基于当前查询日的干支
  五行趋势做整体性推演描述，不必逐日精算。

### 3. 缘分/配对（对应 `match` 命令）

- 三个维度都给到：`shengxiaoRelation`（生肖）、`xingzuoRelation`（星座元素）、
  `dayMasterWuxingRelation`（八字日主五行）。三者结论可能不完全一致，这是
  正常的——明确告诉用户"不同体系角度不同，可以互相参考，不必纠结哪个才是
  '标准答案'"。
- 措辞上避免"不合适""克死对方"这种攻击性强的断言。即使是"相冲""相克"，
  也解释成"性格反差大，需要多沟通/多包容"，落到具体相处建议（比如
  沟通节奏、决策分工）上，而不是暗示分手或不能在一起。
- 结构建议：先给一句整体印象 → 分别说生肖关系、星座元素关系、五行生克关系
  各自代表什么倾向 → 收尾给 2~3 条相处建议。
- 如果只有出生日期没有具体时辰，八字日主仍可算（默认时柱会按 00:00 计算，
  可以提醒用户"若知道准确出生时辰，日主分析会更精准"）。

## 关于西方占星每日运势文案

`Horoscope` 参考项目里的每日/每周/每月运势原本是从一个第三方 API
（`aliyun.zhanxingfang.com`）实时拉取的文本，该接口不在允许访问的网络范围内、
内容也未必仍然可用，所以不要尝试请求它。取而代之：用 `fortune.js` 算出的
真实天文历法数据（星座、日期、老黄历宜忌等）作为"事实锚点"，由你自己
原创撰写运势文案——语气可以参考市面上常见的星座运势风格（活泼、口语化、
给具体场景建议），但内容要自己组织，不要虚构说这是"从某网站获取的"。

## 输出格式建议

- 默认用连贯的中文段落或分点小标题呈现，不必做成表格，除非用户明确要
  多人对比。
- 若用户想要更视觉化的呈现（比如"帮我做一张命盘图/运势卡片"），可以用
  Visualizer 或生成一个简单的 HTML/SVG 命盘图，把 `bazi.full`（四柱）、
  五行、生肖、星座这些结构化字段放进去。
