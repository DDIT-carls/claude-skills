# 常见健康/体检指标参考范围

用户询问体检报告数值、想知道"这个指标算不算正常"时查阅。以下为常见参考区间，不同检测机构/仪器、不同人群（年龄、性别、是否孕期）会有差异，具体请以体检报告上标注的参考范围及医生解读为准。

## 基础生命体征

| 指标 | 参考范围 |
|---|---|
| 静息心率 | 60-100 次/分钟 |
| 血压（收缩压/舒张压） | 收缩压 < 120 mmHg，舒张压 < 80 mmHg 为理想；≥140/90 mmHg 通常诊断为高血压（具体分级以医生判断为准） |
| 体温（发热判断） | 口温 ≥ 37.3°C 或腋温 ≥ 37.2°C 常被视为发热，不同测量方式略有差异 |

## 代谢相关

| 指标 | 参考范围 |
|---|---|
| 空腹血糖 | 约 3.9-6.1 mmol/L（≥7.0 mmol/L 需警惕糖尿病，具体以医生诊断为准） |
| 总胆固醇 | 一般建议 < 5.2 mmol/L，具体目标因个体心血管风险不同而异 |
| 甘油三酯 | < 1.7 mmol/L |
| 高密度脂蛋白胆固醇（HDL，"好"胆固醇） | 男性 > 1.0 mmol/L，女性 > 1.3 mmol/L（越高越好） |
| 低密度脂蛋白胆固醇（LDL，"坏"胆固醇） | 一般建议 < 3.4 mmol/L，高危人群目标更低 |

## 体重与体脂

| 指标 | 分类 |
|---|---|
| BMI（体重指数 = 体重 kg / 身高 m²） | 中国标准：偏瘦 < 18.5；正常 18.5-23.9；超重 24.0-27.9；肥胖 ≥ 28.0 |
| 腰围 | 男性 ≥ 90 cm、女性 ≥ 85 cm 提示腹型肥胖，心血管代谢风险增加 |

## 代谢综合征（满足以下 3 项及以上提示代谢综合征风险）

1. 血压：收缩压 ≥ 130 mmHg 和/或舒张压 ≥ 85 mmHg
2. 甘油三酯：≥ 1.7 mmol/L
3. 高密度脂蛋白胆固醇：男性 ≤ 1.04 mmol/L，女性 ≤ 1.3 mmol/L
4. 空腹血糖：≥ 5.6 mmol/L
5. 腰围：男性 ≥ 90 cm，女性 ≥ 80 cm（或腰臀比：男性 ≥ 0.90，女性 ≥ 0.85）

---

回答用户体检指标问题时，建议格式：

- **该指标的含义**（一句话说明是什么、反映什么）
- **参考范围** 及 用户提供的数值 落在哪个区间
- **偏高/偏低可能提示什么**（不做诊断，只讲常见关联）
- **建议**（是否需要复查、调整生活方式，还是建议尽快就医）
