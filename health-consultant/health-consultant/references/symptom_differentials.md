# 症状深度鉴别参考：咳嗽/咳痰、胸痛

`common_diseases.md` 里的条目是按"病"来组织的，比较适合用户已经大致知道自己得的是什么病、或者症状比较典型的情况。但"咳嗽"和"胸痛"这类症状背后可能对应的疾病谱很广、轻重差异极大，用户描述往往也是先说症状而不是病名，所以单独整理一份更细的**症状鉴别参考**，帮助更准确地判断严重程度、给出更贴切的科室建议。使用方式：用户描述咳嗽或胸痛相关症状时，优先查阅本文件，而不是直接套用 `common_diseases.md` 里"咳嗽"那一条。

---

## 一、咳嗽与咳痰

### 基本概念

咳嗽是一种保护性反射，用于清除呼吸道内的异物、分泌物或刺激物，本身**不是一种疾病，而是一种症状**。咳嗽伴有痰液排出称为"湿性咳嗽"（咳痰），不伴痰或痰很少称为"干性咳嗽"（干咳）。痰是气管/支气管/肺泡的分泌物，不包括口鼻咽喉的黏液。

### 按病程分类（对判断严重程度很关键）

| 病程 | 分类 | 常见病因 |
|---|---|---|
| < 3 周 | 急性咳嗽 | 感冒、急性支气管炎、肺炎等呼吸道感染；异物吸入 |
| 3-8 周 | 亚急性咳嗽 | 感染后咳嗽（气道高反应性尚未恢复）、原因较复杂，需要观察是否发展为慢性 |
| > 8 周 | 慢性咳嗽 | 咳嗽变异性哮喘、上呼吸道咳嗽综合征（过敏性鼻炎/鼻窦炎引起的鼻涕倒流）、胃食管反流性咳嗽、慢性支气管炎等，其中前两者最常见 |

**实用判断：咳嗽超过 3 周就不建议再"自己扛"，应该就医评估；超过 8 周属于慢性咳嗽，病因往往不是简单感冒，更应就诊呼吸内科系统排查。**

### 常见病因分类（供参考，不用逐一列给用户，按需选用）

- **呼吸道本身**：咽喉炎、急/慢性支气管炎、支气管扩张、支气管哮喘、肺炎、肺结核、异物、肿瘤
- **胸膜疾病**：胸膜炎、胸腔积液
- **心血管疾病**：心衰导致肺淤血/肺水肿、肺栓塞
- **其他**：胃食管反流、服用某类降压药（ACEI 类）引起的干咳、习惯性/心理性咳嗽

### 咳嗽性质与音色提示的方向（科普参考，不做诊断）

- **干咳**：常见于急性咽喉炎早期、支气管炎初期、气管受压、胸膜疾病
- **湿咳（咳痰）**：常见于慢性支气管炎、支气管扩张、肺炎、肺脓肿
- **声音嘶哑**：提示声带受累（炎症或压迫）
- **阵发性剧咳伴高调吸气声**（"鸡鸣样"）：儿童多见于百日咳，或喉部/气管受压
- **咳嗽声音低微无力**：见于严重肺气肿、身体极度虚弱者，本身也是需要重视的信号

### 咳痰的量/颜色/性状提示方向

- 白色黏液痰：多见于普通感冒、慢性支气管炎缓解期
- 黄脓痰：提示细菌性感染可能性增加
- 大量脓痰或有异味：警惕支气管扩张、肺脓肿
- 痰中带血/咯血：需要及时就医排查，可能提示支气管扩张、肺结核、肿瘤等，不能自行判断为"上火"

### 伴随症状提示方向

| 伴随症状 | 常提示 |
|---|---|
| 发热 | 呼吸道感染（普通感冒、肺炎、支气管炎等） |
| 胸痛 | 肺炎、胸膜炎、肺栓塞、气胸等——需结合下文"胸痛"部分判断 |
| 呼吸困难 | 哮喘、慢阻肺、重症肺炎、气胸、心衰等，属于需要尽快评估的信号 |
| 咯血 | 支气管扩张、肺结核、肿瘤等，建议尽快就医 |
| 明显消瘦、夜间盗汗、午后低热 | 需要警惕肺结核等消耗性疾病，建议及时就医排查 |
| 杵状指（指端增粗如鼓槌） | 提示慢性缺氧性疾病，如支气管扩张、慢性肺病、肿瘤等，建议就医 |

### 家庭护理与治疗原则

- 单纯病毒感染引起的急性咳嗽多可自愈，注意休息、多饮水、保持室内空气湿润。
- 非处方镇咳药/祛痰药可以短期缓解症状，但**关键是找到并处理引起咳嗽的原发病因**，而不是单靠镇咳药"压住"咳嗽——尤其是有痰的湿咳，一般不建议单纯用强力镇咳药抑制排痰。
- 不建议给出具体药物名称和剂量，提醒用户参考说明书或咨询药师/医生。

### 建议就诊科室与就医时机

- **建议就诊科室**：呼吸内科（怀疑反流相关可结合消化内科，怀疑过敏/鼻炎相关可结合耳鼻喉科或过敏科）。
- **应尽快就医的信号**（与 `red_flags.md` 呼应）：咳血、呼吸困难、持续高热、明显消瘦或夜间盗汗、咳嗽超过 3 周不缓解、儿童出现阵发性剧咳伴高调吸气声。

## 二、胸痛

### 核心原则：胸痛不等于心脏病，但必须优先排除 4 种高危疾病

胸痛的病因非常广，从良性的肋间神经痛、肌肉拉伤，到可能致命的心脑血管急症都有。**无论疼痛剧烈程度如何，只要是胸痛，第一步都应该先排除以下 4 种高危疾病**，因为一旦漏诊都可能致命：

1. **急性冠脉综合征（心绞痛/心肌梗死）**
2. **主动脉夹层**
3. **急性肺栓塞**
4. **张力性气胸**

这 4 种情况的典型信号已经在 `red_flags.md` 中列出，一旦怀疑，第一反应应该是**立即拨打 120 或送急诊，不要自行开车、不要在家观察等待**。

### 不同性质的胸痛常提示的方向（科普参考，不做诊断）

| 疼痛性质/表现 | 常见方向 |
|---|---|
| 压榨样痛、伴窒息感，活动或情绪激动诱发，休息/含服硝酸甘油可缓解 | 心绞痛，建议尽快心内科就诊评估 |
| 持续剧痛不缓解，含药也不缓解，可伴口唇/四肢发绀 | 需高度怀疑急性心肌梗死，**立即就医** |
| "撕裂样"剧痛，可放射到背部 | 需高度怀疑主动脉夹层，**立即就医**，切忌自行使用扩血管药物或剧烈活动 |
| 突发剧烈胸痛伴呼吸困难，尤其有慢阻肺等基础病史 | 需高度怀疑气胸，**立即就医** |
| 突发胸痛伴严重呼吸困难、发绀，甚至晕厥 | 需高度怀疑肺栓塞，**立即就医** |
| 灼痛/烧灼感，餐后或平躺时加重 | 提示食管炎/胃食管反流，可先观察调整饮食习惯，持续不缓解建议消化内科就诊 |
| 一过性针刺样/闪电样疼痛，局部有压痛点 | 多见于肋间神经痛，多数无需紧张，可自行观察 |
| 沿单侧神经走行的成簇小水疱伴剧痛，不过中线 | 提示带状疱疹，建议皮肤科/疼痛科就诊 |
| 咳嗽、深呼吸或体位改变时疼痛加剧 | 提示胸膜或心包受累（胸膜炎、心包炎），建议及时就医 |
| 隐痛/闷痛，逐渐加重，可能伴咳嗽、消瘦 | 需警惕肺部或纵隔占位，建议尽快就医检查 |
| 反复胸闷心慌，检查（心电图、心脏彩超）均正常，运动后症状反而减轻 | 可能与焦虑紧张相关的功能性表现（心脏神经官能症样），建议先经医生排除器质性问题，再考虑心理/情绪方面的调节，不建议自行判断或自行服用相关药物 |

### 伴随症状提示方向

| 伴随症状 | 常提示 |
|---|---|
| 咳嗽 | 气管/支气管/胸膜疾病 |
| 吞咽困难 | 食管相关疾病 |
| 咯血 | 肺结核、肺栓塞、肺部肿瘤，建议尽快就医 |
| 呼吸困难 | 肺炎、气胸、胸腔积液、肺栓塞等，需要重视 |

### 处理原则

- 一旦怀疑上述 4 种高危胸痛，**立即拨打 120 或送急诊**，过程中让患者尽量保持安静休息，避免自行剧烈活动。
- 有明确冠心病史、随身携带急救药物（如硝酸甘油）的用户，可以按医生此前的指导使用，但仍应同时联系送医，不能替代就医。
- 一般性、轻度的胸痛（如肋间神经痛、单纯肌肉拉伤）通常不需要过度紧张，但如果性质不典型、反复发作或用户本身有心血管危险因素（高血压、糖尿病、吸烟、肥胖、家族史等），仍建议倾向于"先就医排除，而不是先自行判断为良性"。

### 建议就诊科室

- 怀疑心源性：心血管内科/急诊
- 怀疑主动脉夹层、气胸、肺栓塞：急诊科（这三种都需要紧急处理，不是普通门诊能解决的）
- 怀疑消化道相关（反流）：消化内科
- 怀疑肌肉骨骼/神经相关（肋间神经痛、肋软骨炎）：骨科或疼痛科
- 反复胸闷心慌但检查正常，怀疑功能性因素：可先心血管内科排查器质性疾病，再考虑精神心理科/心理咨询介入
